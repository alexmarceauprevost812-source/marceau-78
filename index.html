Écriture

Un espace d'écriture minimaliste, avec un assistant qui répond à côté. La page est vide, tu écris au milieu, et tout le reste s'efface.

  • Python + Tkinter
  • Aucune dépendance
  • Un seul fichier
  • Testé sous Linux
Télécharger ecriture.py Essayer dans le navigateur Voir le code

À quoi ça ressemble

La saisie démarre au centre. Dès la première question, elle glisse vers le bas et la conversation prend la place au-dessus.

Deux IA au choix

Le menu sous la boîte de saisie permet de changer en cours de route : le fil de la conversation suit.

Gratuit · hors ligne

Les modèles locaux d'Ollama

mistral, llama3.2, qwen3, gemma3, deepseek-r1… Ils tournent sur ta machine, sans compte ni carte de crédit.

Pas d'accès à Internet : on leur demande de le dire plutôt que d'inventer.

Payant · clé API

Claude + recherche web

Pour tout ce qui a pu changer récemment — actualité, prix, horaires, météo. Les sources citées s'affichent sous la réponse et s'ouvrent au clic.

La clé reste sur ta machine, dans ~/.config/ecriture/, en lecture seule pour toi.

Les détails qui comptent

Trois choses qu'on remarque à l'usage.

Ça s'écrit devant toi

La réponse arrive lettre par lettre derrière un curseur orange, en une seconde et demie quelle que soit sa longueur.

Ça parle d'ici

L'assistant répond en français québécois familier. Un réglage (STYLE_QUEBECOIS) le remet en français standard.

Les plans se dessinent

Des étapes dans la réponse ? Elles se redessinent en schéma, avec un courant vert qui les allume l'une après l'autre.

Installation

Un fichier, la bibliothèque standard, et c'est tout.

# Tkinter, s'il manque (Debian / Ubuntu)
$ sudo apt install python3-tk

# Lancer
$ python3 ecriture.py

Pour les modèles gratuits, installe Ollama depuis ollama.com, puis :

$ ollama serve
$ ollama pull mistral
