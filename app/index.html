OLLAMA_ORIGINS=… ollama serve

    L'application

    Version…

    Elle se met à jour toute seule : chaque fois que tu l'ouvres, elle va chercher la dernière version en arrière-plan.

    Pour la version ordinateur, avec le Codex : télécharger Écriture.

    ▤ Codex

    Le Codex ouvre un projet GitHub, colore le code, pis laisse l'IA le lire, l'écrire pis le corriger avec toi.

    Il travaille dans tes fichiers, faque il vit dans la version ordinateur — c'est la même app, avec le même menu.

    ⬇ Télécharger Écriture

    Un seul fichier. Tu l'ouvres avec python3 ecriture.py et il se tient à jour tout seul après.
